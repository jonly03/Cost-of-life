# Methodology

## First-principles rule

Prefer:

physical requirement → resource requirement → delivery mechanism → infrastructure → economic good/service → price

over:

budget category → price

## Claim discipline

Important claims preserve:

Claim → Evidence → Source → Assumptions → Confidence/Uncertainty → Scope → Counterevidence/Limitations → PEOM implication

Distinguish measured quantities, estimates, model assumptions, derived calculations, hypotheses, interpretations, and normative judgments.

An estimate must never silently become a fact.

## Core distinctions

Requirement ≠ Consumption ≠ Replenishment.

Observation window ≠ physiological replenishment horizon.

Experiment 001 uses a 24-hour observation window, but biological dependencies may operate on much shorter or longer timescales.

## Dependency classes

- Flow
- Stock
- State
- Process
- Capacity
- Externally mediated

## Boundary convention for EXP-0001

Experiment 001 models a living human organism at t0 with preexisting internal reserves and functioning baseline physiological systems. It asks which external conditions, flows, internal processes, capacities, and reserve states must remain available or occur during the following 24 hours for continued viability and explicitly defined higher functional states.

Initial physiological stocks are inherited boundary conditions for this experiment, not free resources in a lifetime model.

## Inventory Blindness

Inventory Blindness is the error of inferring an external replenishment requirement directly from observed usage without accounting for stored reserves.

Observed use does not imply equal external input when internal stock exists.
